# CODE KOLKATA (Edition 01 — 2026)

> **"Two Communities. One City. Ship Something Legendary."**  
> *Discovering Kolkata Through AI & Innovation*

**CODE KOLKATA** is an intensive 8-hour technology build sprint hosted collaboratively by **Bug Busters Community** and **Anibotix Robotics** in Kolkata, India. It brings together over 100 students, early-career developers, roboticists, and designers under one roof to build working products from scratch, learn from seasoned industry mentors, and demo live in front of a panel of judges.

## ❓ Frequently Asked Questions (FAQ)

#### Q1: Who can take part in CODE KOLKATA?
**A**: Open to all students, early-career developers, designers, and robotics builders from any college or community. The application is solo; during the buildathon, teams will be formed by random selection into squads of 4.

#### Q2: Do I need a finished idea to register?
**A**: No. You can register with just a track preference. The official challenge briefs and themes are revealed live during the opening ceremony.

#### Q3: What does it cost to participate?
**A**: Application and entry are **100% free**. Meals, high-speed Wi-Fi, power, and coffee are provided on-site at Jadavpur University.

#### Q4: What should I bring with me?
**A**: Your laptop, power brick/charger, student ID card, and a valid government ID (Aadhaar / Voter ID / Passport). Hardware builders may bring dev boards and prototyping components.

#### Q5: How are projects judged?
**A**: With a strict, transparent rubric:
1. **Working demo first** (must be functional).
2. **Originality and innovation**.
3. **Technical execution & code quality**.
4. **Clarity of story and pitch**.

#### Q6: How do I become a sponsor or community partner?
**A**: Submit your organization's details through our [Partner Registration form](/partner-registration) or reach out directly to `community.bugbusters@gmail.com`.

## 💻 Tech Stack & Architecture

This repository contains the full single-page application (SPA) and serverless backend API:

### Frontend
* **Core Framework**: React 19 (`react` + `react-dom`)
* **Build System**: Vite 8 with `@vitejs/plugin-react`
* **Routing**: React Router DOM v7
* **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) with custom retro-futuristic dark mode theme variables
* **Motion & Polish**: 
  * `lenis` for physics-based smooth scrolling
  * IntersectionObserver-driven scroll reveals (`Reveal.jsx`)
  * Animated stat counters (`CountUp.jsx`) and typewriter headers (`Typewriter.jsx`)
  * Infinite sponsor & partner marquees (`Marquee.jsx`, `SponPartMarquee.jsx`)
* **Soundtrack**: Opt-in background chiptune audio (`SuperMario.mp3`) with client-side state caching

### Backend & API
* **Node.js**: Standalone HTTP server (`server.js`) & Vercel serverless functions (`/api/community-partner.js`)
* **Database**: MongoDB (`mongodb` v7) database storing partner and attendee submissions
* **Transactional Mail**: Resend SDK (`resend` v6) for automatic email confirmations
* **Analytics**: Microsoft Clarity integration

## 🚀 Getting Started & Local Development

### Prerequisites
* **Node.js**: v20.19.0+ or v22.12.0+ (Tested with v24.22)
* **npm**: v10.0.0+

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Bug-Busters-Community/code-kolkata.git
   cd code-kolkata/frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in `frontend/` (refer to `.env.example`):
   ```env
   PORT=3000
   MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/code_kolkata
   RESEND_API_KEY=re_your_api_key_here
   EMAIL_FROM=onboarding@resend.dev
   ```

4. **Run Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

5. **Build for Production:**
   ```bash
   npm run build
   ```

6. **Run Local Production Server:**
   ```bash
   npm run server
   ```
